# Golden frames of the haptics wire (vsock 5557), the contract between the
# guest's vibrator HAL (android/lineage-24/overlay/vibrator) and the host
# (Andarium/AndariumCore HapticsProtocol.swift).
#
# One frame per line: `name: <hex bytes>`. A line that starts with `#` is a
# comment, and the comment above a frame says what it means. Every number is
# little endian; a float32 is IEEE 754.
#
# Frame ids: the primitive and effect codes are android.hardware.vibrator's
# CompositePrimitive and Effect numbers (CLICK 1, THUD 2 ... for a primitive;
# CLICK 0, DOUBLE_CLICK 1 ... TEXTURE_TICK 21 for an effect), and an effect's
# strength is EffectStrength (LIGHT 0, MEDIUM 1, STRONG 2).
#
# The guest's encoder produces every `play-`, `intensity-` and `stop` frame
# from the call described above it, and its decoder reads every `ack-` frame.
# The host's decoder reads every `play-`, `intensity-` and `stop` frame as
# described, encodes every `ack-` frame, and refuses every `reject-` frame
# (the guest's encoder never produces one).
